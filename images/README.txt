Put your product photos in this folder (jpg, png or webp).

Then point a product at it in js/products.js, for example:
    image: "images/maternity-pillow.jpg"

Tips
- Square photos (about 800 x 800 pixels) look best.
- Keep each file under about 200 KB so the site loads fast on phones.
- Use lowercase names with dashes and no spaces: maternity-pillow.jpg

If you use the dashboard (admin/), you do not need this folder: the dashboard
uploads and resizes photos for you automatically.
